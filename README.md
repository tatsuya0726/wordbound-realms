# Wordbound Realms（ことばの幻界）

英語学習用の HD-2D 風 RPG。ブラウザだけで動きます（`index.html` を開くだけ）。

- 戦闘：Attack＝単語 / Spell＝文法 / Echo＝リスニング（音声読み上げ）
- 町：英語の会話（日本語訳・単語タップで意味表示）、店・宿屋での受け答えクイズ
- イベント：橋の番兵の文法試験、港のアナウンス聞き取り、学者との言葉の決闘、最終ボス
- 単語帳：間違えた問題を記録し、復習クイズで解き直し

## 技術メモ

- 単一ファイル `index.html`（HTML/CSS/JS）。3D 描画は three.js r128（cdnjs から読み込み）。
- WebGL が使えない環境では 2D マップ表示に自動で切り替わる。
- セーブはブラウザの localStorage。

## 遊び方

`index.html` をブラウザで開く。操作は矢印キー/WASD で移動、Z・Enter で決定、X・Esc でメニュー。
