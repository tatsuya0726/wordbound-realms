# ごちゃまぜモンスター — ことばでつながる世界

英語学習とモンスター収集を組み合わせた、横画面向け HD-2D 風 RPG。ブラウザだけで動きます。

**遊ぶ:** https://tatsuya0726.github.io/wordbound-realms/

**Godot試作版:** https://tatsuya0726.github.io/wordbound-realms/godot/ — 村とバトルをGodotでHD-2D化した比較用の試作。本編のセーブは読み取りのみ（ソースは `godot-src/`）。

**開発の引き継ぎ:** [CLAUDE.md](CLAUDE.md) → [HANDOFF.md](HANDOFF.md)。このリポジトリが正本です。

## 横画面と三層の世界

- 街・探索は画面全面を使い、会話やメニューを開いた時だけウィンドウを重ねます。移動はマップ左下の立体的なスティック、右下がA/Bボタンです。4方向の移動で、指がパッド外に出てもドラッグを捕捉し、離す・画面を切り替える・フォーカスを失うと停止します。
- 戦闘は景色・HP/MP・英語問題とコマンドの領域を分離。縦画面では上下に並び替えます。
- 右上の「世界地図」で地上・空中・地下の素材マップを表示し、村・空中庭園・地底水晶庭へ移動できます。全体地図は世界観の案内図で、画像の全地点が歩けるわけではありません。
- 空中庭園と地底水晶庭は、それぞれ案内人・英語の試練・商人・野生の仲間・帰還口を持つ探索エリアです。学習帯の3問中2問正解すると印と木の実3個を受け取れます（報酬は各1回）。
- キキとネネが同行します。右上の「相談」で次の目的・英語練習・地図を開けます。従来の村固定NPCから、主人公を支えるサポート役になりました。
- 街の建物・地面・配色、戦闘背景と敵の見た目を素材に合わせて刷新。主人公とキキ・ネネは専用の4方向歩行シート、街の大人NPCはDrive由来の立ち絵を使います。
- 公開URLとセーブのキーは従来のままです。

## 遊びの内容

- 戦闘：Attack＝単語 / Spell＝文法 / Echo＝リスニング（音声読み上げ）。連続正解でコンボ。
- 職業：書記官（単語に強い）/ 賢者（文法に強い）/ 聴き手（リスニングに強い）。村の「役割の館」で変更。
- 町：英語の会話（日本語訳・単語タップで意味表示）、店・宿屋での受け答えクイズ。
- イベント：橋の番兵の文法試験、港のアナウンス聞き取り、学者との言葉の決闘、最終ボス。
- 第2章「夢の島」：クリア後に解放。鏡の賢者（文法）とこだまの子（リスニング）の試練のあと、悪夢の主と戦う。
- 単語帳：間違えた問題を記録し、復習クイズで解き直し。

## 仲間と学習の追加

- 8種の仲間、個体IDごとの所有、最大3体の同行、勝利時の育成。旅人の戦闘に連携攻撃で参加し、HP・MPは共有します。
- 野生の仲間に Item → Berry で餌を与え、別の Scout コマンドで表示確率を確認して勧誘。満員でも牧場に加入し、メニューの Companions → Team で編成できます。木の実は店で補充できます。
- 村・港町の Companions → Breed で4通りの配合。確定後に指定した親2個体を消費し、Lv.1の子が生まれます。保存に失敗した場合は取り消します。図鑑に生息地とレシピを表示します。
- 呪文用370問（穴埋め280問・日常会話90問）、小1〜中3を目安とする9学習帯。Settings で選択できます。単語・聴解・ストーリーの試験は従来の3段階です。
- 戦闘の誤答でも通常の50％で攻撃・回復します（整数丸めあり、連続正解ボーナスはリセット）。
- 村にキキ・ネネの会話と呪文練習を追加。NPC会話は日本語訳を英文の上に表示し、従来どおり非表示にもできます。
- 旧セーブ初回読込時にバックアップを保持し、タネチュー1体と木の実3個を追加します。既存の冒険進行・HD-2Dフィールドは継続します。

独立した3体分のHP・行動システムは含みません。同行する仲間は旅人の攻撃を支援します。

## 既存の改善

- HP・MP・経験値のバーを表示。探索と戦闘でそれぞれ画面構成を切り替えます。
- 学習ノートに出会った問題数・復習待ち・克服数を表示。間違えた後に2回連続正解すると苦手リストを卒業（再び間違えると復習対象に戻る）。
- メニューの冒険記録で進行を確認。第1章クリア後は長老から夢の島へ進み、各試練に応じて目的を案内。
- 戦闘の正解解説は初期設定で手動送り。設定で従来の自動送りに変更可能。
- 賢者のSpellは表示・使用条件・消費をすべてMP1に統一。
- 会話・戦闘・復習などの完了時に自動保存。保存状態を表示し、既存セーブがある場合は新規ゲーム開始前に上書きを確認。保存先のキーは従来と共通。

## 開発用の確認

ゲームは `index.html`、`companion-*.js`、`world-ui.js`、`walk-sprites.js`、`party-battle.js`、`landscape.css`、`party-ui.css`、`assets/` を静的配信して動作します。テストのみNode.jsを使います。

```sh
npm install
npx playwright install chromium
npm test
```

既存セーブ、賢者のMP1での呪文、復習・保存、第2章の目的、新規ゲームのキャンセル、スマホ幅、Three.js非読込時の起動を確認します。画像と結果は `qa/` に生成します。インストール済みEdgeを使う場合は環境変数 `BROWSER_CHANNEL=msedge` を指定できます。全ストーリーの通しプレイと実機音声の確認は別途必要です。

## 見た目

- フィールド：three.js による 3D 世界にドット絵スプライトを置く HD-2D 風。町・世界・洞窟・塔・夢の島ごとに光と色が違う。
- 戦闘：場所ごとに描き分けた背景（草原・洞窟・海辺・塔・夢の島）。地上の敵は接地、飛行種のみ浮遊。攻撃の踏み込みと被弾を表示。
- すべてオリジナルのキャラクター・背景。WebGL が使えない環境では 2D 表示に切り替わる。

## 技術メモ

- 本体 `index.html`（HTML/CSS/JS）と仲間のデータ・ルール・UIモジュール。3D 描画は three.js r128（cdnjs から読み込み）。
- セーブはブラウザの localStorage。

## 操作

矢印キー/WASD で移動、Z・Enter で決定、X・Esc でメニュー、数字キー 1–4 で解答、R で音声をもう一度。スマホは画面下のボタン。

## 3体戦闘・歩行アニメーション（2026-10-22）

- 通常の敵は1〜3体、物語ボスは1体。敵ごとに頭上の連続HPバーを表示し、あいてを選ぶコマンドで攻撃・木の実・スカウトの対象を変更できます。
- 倒した敵・加入した敵は反撃せず、残った敵との戦闘を続行します。敵の数に合わせて被ダメージを調整しています。
- 味方の同行モンスターは最大3体を表示。従来の連携攻撃と共有HP・MPを維持し、戦闘画面に「共有」と明記しています。
- 黒地に白枠のステータス・仲間・メッセージ／コマンド枠と、全幅の背景で構成。敵の画像サイズは縦横どちらでも重ならないよう制限します。
- 主人公は小柄でわんぱくな少年。少年・キキ・ネネは各4方向×3フレーム、停止時はニュートラル姿勢。猫は主人公の通った経路を追い、足元を固定して歩きます。
- キキはクリーム色、ネネは白銀色。ユーザー提供の全身画像を参照して built-in imagegen で作成し、64pxセルに共通倍率で整形。生成プロンプトと参照対応は `assets/walk/PROMPTS.md`。
- タイトルは三層世界の地図、光の演出、少年と2匹の並びを追加しました。
- `party-test.cjs` は対象切替・個別の餌とスカウト・複数敵の勝敗と報酬・地上／飛行の描画・4方向歩行・3体表示・画面回転を検証します。
