# ごちゃまぜモンスター：ことばでつながる世界

英語の問題に答えて戦い、ほめ言葉でモンスターを仲間にし、配合と冒険で「ことのは島」を育てるブラウザーRPGです。横画面を基本に、タッチ・キーボード・標準配置のゲームパッドで操作できます。

- 公開ゲーム：https://tatsuya0726.github.io/wordbound-realms/
- 継続開発するリポジトリ：https://github.com/tatsuya0726/wordbound-realms
- 商用リリース前の確認事項：[COMMERCIAL-READINESS.md](docs/COMMERCIAL-READINESS.md)

このREADMEは現在の操作・実装の案内です。作業中の変更が公開URLに反映されているとは限りません。販売準備が完了したことや、すべての素材の商用利用が確認済みであることを示すものではありません。

## 最初の冒険

1. このブラウザーで使うユーザー名を設定し、「はじめから」で学習帯を選びます。
2. ことのは島の北にある城に入り、王様から依頼を受けます。
3. 広場の入口から「はじまりの草原」へ。戦いながら仲間を集め、まずは3体のチームを目指します。
4. 島へ帰り、宿屋で回復、仲間メニューで編成、配合の館で育成を進めます。
5. ボスを倒すと次の世界が開きます。仲間や勝利で島が発展し、闘技場や城の地下から向かう異世界にも挑めます。

探索中の「次の一歩」を押すと、冒険ガイドを開けます。現在の目標と、対応する地点までの方向・歩数の目安を表示します。自動移動ではなく、すべての地域で経路を案内するものでもありません。相手を向くと「話す」「看板を読む」「挑戦する」などの操作案内が出ます。

## 戦闘・スカウト・配合

- 味方は最大3体。それぞれ独立したHP・SPを持ちます。通常の敵は1〜3体で、戦闘不能になった仲間は宿屋などで復帰できます。
- 「呪文」から「ことばの光」や習得した技を選び、英語の問題に答えます。「ことばの光」はSP 0。「聴く呪文」はSP 0で、聴解と自身の回復を組み合わせた技です。技ごとの消費SP・効果は選択画面で確認できます。
- 間違えても攻撃・回復の効果は基本的に半分残ります。正解を確認して、次に生かしましょう。
- 「どうぐ」から木の実をあげると、対象が好きなほめ言葉のヒントを得られます。「スカウト」で英語のほめ言葉を選び、仲間になる可能性を高めます。配合限定の種など、スカウトできない相手もいます。
- 敵が複数いるときは対象を確認してください。「呪文」内の「対象を変更」でも選び直せます。
- 危なくなったら「にげる」。ボス戦など、逃げられない戦闘もあります。全滅すると所持金が半分になります。
- 配合は指定した親2体を消費し、新しい子を生みます。確認画面の親・子・レシピを見てから決定してください。同じ種でも個体ごとに管理されます。保存に失敗した場合は配合を確定しない仕組みです。

## 英語学習

設定で学習帯、問題の難しさ、ふりがな、読み上げや音量などを調整できます。単語・文法・聴解・会話の問題があり、学習帯別の追加問題は370問です。

答えを選ぶと、正解の選択肢が緑、間違えて選んだ選択肢が赤で短く表示されてから結果に進みます。続けて正解すると「2問連続！」のように表示され、正解音が少しずつ高くなります（連続数は保存されず、再読み込みで0に戻ります）。

間違えた問題は学習ノートに記録されます。その後2回連続で正解すると復習待ちから外れ、再び間違えると戻ります。港のアナウンス問題も復習できます。

読み上げにはブラウザー・OSの音声機能を使います。端末や音声設定によって利用できないことがあります。聴解・発音問題で聞こえないときは「音声が聞こえないとき：英文を表示」を開くと、文章を読んで回答できます。音声が聞ける場合も任意で使える補助機能です。

## 操作

| 入力 | 移動 | 決定・会話 | 戻る・メニュー |
|---|---|---|---|
| タッチ | 左下のスティック | A | B |
| キーボード | 矢印 / WASD | Z / Enter | X / Esc |
| 標準配置のゲームパッド | 左スティック / 十字キー | 下側のボタン | 右側のボタン / Start |

- キーボードの数字キーで解答を選択、Rで音声をもう一度再生できます。メニューでは矢印で選択、Tabでボタンなどへフォーカスを移せます。
- ゲームパッドはブラウザーが `standard` 配置として認識したものに対応します。下側・右側という位置が基準で、機種に印刷されたボタン名とは限りません。
- 接続直後や画面復帰時は、スティックやボタンを一度離してから操作してください。文字入力欄ではキーボードまたはタッチを使ってください。
- 音声の開始に画面タップやキー入力が必要な場合があります。実機ごとのタッチ・音声・コントローラー動作は、開発用ブラウザー試験とは別に確認が必要です。

## 保存と復元

会話・戦闘の終了時などに自動保存します。データはこの端末・ブラウザーのlocalStorageに保存され、端末間の同期はありません。ユーザー名はローカルでセーブを分けるための表示名で、認証アカウントではありません。

- 最初のユーザー作成時に、従来の `wordbound-realms-v1` のセーブをコピーします。以降はユーザー別に保存し、通常モードとデバッグモードも分離します。
- 保存状態は画面上部で確認できます。容量不足や保存が禁止された環境では、進行を保存できないことがあります。
- 内容が変わる保存の前に、直前のセーブを1世代の控えとして保持します。読み込めない保存データがあり、有効な控えがある場合は、タイトルで「前回の控えから復元」を選べます。確認して復元すると、最後の変更が失われる場合があります。読めなかった原本は別に保管します。
- 控えも同じブラウザー内にあります。ブラウザーデータの削除、端末紛失、プライベートブラウズの終了などに対する外部バックアップではありません。すべての破損状態を復元できる保証もありません。
- 「はじめから」は既存セーブがある場合に上書きを確認します。残したい冒険がある場合は別のユーザーを作成してください。

## 開発とテスト

本編はHTML / JavaScript / CSSと画像・音声を静的配信する構成です。Unityプロジェクトではありません。`index.html` が状態と進行の中心で、仲間・戦闘・世界・表示を各モジュールが拡張します。読み込み順とグローバル名の衝突に注意してください。

```sh
npm ci
npx playwright install chromium
BROWSER_CHANNEL=chromium npm test
```

Windowsのインストール済みEdgeを利用する場合：

```powershell
$env:BROWSER_CHANNEL='msedge'
npm test
```

個別に確認する場合は、同じ作業フォルダーから対象のテストを実行します。

```sh
node learning-recovery-test.cjs
node save-safety-test.cjs
node save-recovery-browser-test.cjs
node input-access-test.cjs
node island-growth-test.cjs
node town-weather-test.cjs
node game-feel-test.cjs
```

実行対象の一覧は `package.json` の `scripts.test` を確認してください。各ブラウザーテストはローカルサーバーと独立したブラウザーを使い、必要に応じて `qa/` に結果・画像を保存します。`test-quiet.cjs` は音声をミュートし、読み上げを代替するため、テスト成功だけでは実機の発音や音量を保証できません。

主な回帰対象は既存セーブ・個体管理・配合の保存失敗・スカウト・戦闘・図鑑・学習ノート・画面回転・入力です。全ストーリーを初見の操作だけで通す試験、実機iPhone / Android、実物のコントローラー、学習難度と戦闘バランスは別途確認します。具体的な販売前の確認項目は [商用リリース確認表](docs/COMMERCIAL-READINESS.md) にまとめています。

### 主なファイル

- `companion-data.js` / `companion-rules.js` / `companion-ui.js`：仲間データ・個体・配合・UI
- `party-battle.js` / `skill-*.js`：個別HP/SPの戦闘・技
- `island-hub.js` / `island-growth.js` / `rift-worlds.js`：拠点・発展・異世界
- `journey-guide.js`：目標と道案内・遊び方・相手に応じた操作案内
- `accessible-input.js`：キーボード補助・標準配置のゲームパッド
- `local-profiles.js` / `profile-ui.js` / `save-safety.js`：ローカルユーザー・保存の控えと復元
- `music.js`：音量・BGM・クレジット
- `game-feel.js` / `game-feel.css`：効果音（Web Audioで合成、音声ファイルなし）・解答の正誤表示・連続正解の表示

`CLAUDE.md` / `HANDOFF.md` には開発履歴があります。古い共有HPの説明などは当時の仕様であり、現行コードとこのREADMEを優先して確認してください。公開URLのセーブを保護し、コミット・push・公開は依頼者の承認範囲に従って実施します。
