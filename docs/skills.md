# 技とSP

98技を222種へ3枠ずつ割り当てています。通常攻撃とリスニングは従来どおり消費0。固有3枠と継承5枠、最大8枠です。

- 個体ごとのSPを使います。セーブ内部のmp/maxMpを維持しています。
- 技の最低習得レベルと種ごとの習得レベルは異なります。正確な割り当てはspecies-skills.csvを参照してください。継承は親由来の習得閾値を保存し、Lv1では使えません。
- 旧native:種ID:枠の継承技は旧名・旧効果・旧習得レベルで保持します。新しい固有技は共通IDです。
- 攻撃・回復・盾・継続効果は不正解で半分。眠り等の確率も半分。解除・予防は不正解時50%で成功。反動と消費SPは減りません。
- 盾は対象最大HP40%上限。攻撃強化40%、防御強化50%、攻撃低下35%、被ダメージ増加25%、防御軽減40%、暗闇25%上限。同種は加算せず強い効果を保持します。
- 継続効果はラウンド末に処理し、付与ラウンドには発動しません。敵が付与した場合も同じです。戦闘終了で状態を破棄します。
- 蘇生はSPを戻さず、そのラウンドは行動済み。眠り・しびれはボス無効、解除後2ラウンド再拘束を防ぎます。
- 通常敵は3ラウンドごとに習得済み固有技を有限SPで使用できます。封印中は通常攻撃。
- 属性や物理／魔法のテーマは抵抗属性計算を新設するものではありません。

## 進化する技

6系列は同じ枠でLv1→10→22に上位技へ置換。種の固有習得Lvが遅い場合はそのレベル以降。継承はLv3→12→24以降で、親から選んだ上位技がLv1に解禁されることはありません。保存IDは変更せず、読み込み・レベルアップ時に現在レベルから一度だけ解決します。

回復は35（SP3）→75（SP7）→単体全回復（SP16）。不正解は半分、全回復技は最大HP50%の回復。戦闘不能は対象外です。炎・水・雷・盾・攻撃強化にも上位2段階があります。
